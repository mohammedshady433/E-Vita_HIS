# E-Vita
**E-Vita HIS** is a cross-platform Hospital Information System application built with .NET MAUI. It aims to streamline hospital management and healthcare workflows by providing modules for surgery scheduling, patient management, and more. The project is designed to run on Android, iOS, Mac Catalyst, and Windows 10+ devices.

## Features

- Multi-specialty Surgical Operations Reference (General Surgery, Cardiothoracic, Neurosurgery, Orthopedic, Plastic, Urology, Gynecology, Ophthalmology, ENT, Vascular, etc.)
- Cross-platform support (Android, iOS, Mac, Windows)
- Modern UI powered by .NET MAUI
- Integrated resources: app icons, splash screens, images, custom fonts, and raw assets (JSON data for surgical operations)

## Tech Stack

- **Languages:** C#
- **Framework:** .NET 9.0 (MAUI)
- **Packages:**  
  - `CommunityToolkit.HighPerformance`  
  - `CommunityToolkit.Mvvm`  
  - `Microsoft.Maui.Controls`  
  - `Microsoft.Extensions.Logging.Debug`

## Installation

1. **Prerequisites:**
   - Visual Studio 2022 (v17+) with .NET MAUI workload installed
   - Supported OS: Windows 10+, macOS, Android, iOS

2. **Clone the repository:**
   ```sh
   git clone https://github.com/mohammedshady433/E-Vita_HIS.git
   cd E-Vita_HIS
   ```

3. **Open solution:**
   - Open `E-Vita.sln` in Visual Studio.

4. **Build and Run:**
   - Select your target platform (Android, iOS, Windows, Mac)
   - Build and run the project.

## Usage

- Launch the application on your device or emulator.
- Access modules for surgical operations, patient management, and other hospital workflows.
- Consult the integrated reference for various surgical specialties and procedures.
